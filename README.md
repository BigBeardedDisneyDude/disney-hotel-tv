# disney-hotel-tv
Creating my own version of the hotel splash screen, to mimic the vibe

I really enjoy staying at the Disneyland Hotel, and one of my favorite things about it is the home screen you get on the TV. I'd like to be able to have that at home, so I'm trying to recreate it here for fun.

Current features
  <br>Able to set your family name and a trip countdown
  <br>A link to a page dedicated to updates to the parks (and others currently)
  <br>A link to a page with ride wait times
  <br>Links to Disneyland park hours, dining reservations, and a resort map
  <br>An animated background showing the hotel monorail pool with water fall, palm trees and clouds moving in the wind
  <br>Optimized for mobile devices
  <br>Music can be played just like at the hotel
  <br>A ride survey is now available! You can select which rides are most important to you, and they will be broken down by land! Mutliple people per trip can submit their own surveys and the results will display where the highest priorities are
