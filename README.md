# disney-hotel-tv
Creating my own version of the hotel splash screen, to mimic the vibe

I really enjoy staying at the Disneyland Hotel, and one of my favorite things about it is the home screen you get on the TV. I'd like to be able to have that at home, so I'm trying to recreate it here for fun.

Current features
  Able to set your family name and a trip countdown
  A link to a page dedicated to updates to the parks (and others currently)
  A link to a page with ride wait times
  Links to Disneyland park hours, dining reservations, and a resort map
  An animated background showing the hotel monorail pool with water fall, palm trees and clouds moving in the wind
  Optimized for mobile devices
