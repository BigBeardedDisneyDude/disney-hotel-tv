One-time Setup

This app needs a free Firebase project to store responses across devices. Takes about 5 minutes.

1
Go to console.firebase.google.com and create a new project (you can skip Google Analytics).
2
In your project, click Build → Firestore Database → Create database → Start in test mode → choose any region.
3
Click the gear icon → Project settings → scroll to "Your apps" → click the </> (web) icon → register app → copy the firebaseConfig object.
4
Open survey.html in a text editor, find the FIREBASE_CONFIG section near the top of the script, and paste your config values in.
5
Save and push to GitHub. Done! Come back here and refresh.
